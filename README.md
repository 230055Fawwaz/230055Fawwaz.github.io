## 🛠️ Technical Stack & Architecture

- **Markup & Styling**: Semantic HTML5, Vanilla Modern CSS (CSS Custom Properties, CSS Grid, Flexbox, `@media` responsiveness).
- **Typography**: Google Fonts (`Courier Prime`, `Space Mono`, `Lora`).
- **Interactive Logic**: Vanilla JavaScript ES6+ (Zero external npm/framework runtime dependencies).
- **Interactive Features**:
  - Clickable & accessible **Redacted Text (`.redacted`)** with keyboard declassification (`[Enter]` / `[Space]`).
  - **Dynamic Project Filtering**: Filter projects by Network, Web/Desktop, AI/RAG, and Games/VR.
  - **Exhibit Lightbox Modal**: Native `<dialog>` element for high-resolution project screenshots.
  - **Dispatch Terminal Relay**: Asynchronous form dispatch with direct mail fallback.
- **Hosting & Deployment**: Hosted globally on GitHub Pages with `.nojekyll` pipeline bypass and XML sitemap indexing.
